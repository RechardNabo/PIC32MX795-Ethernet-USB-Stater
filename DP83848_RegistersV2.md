### 6.6.1.1 Register Definition

In the register definitions under the 'Default' heading, the following definitions hold true:

- **RW =** Read Write access
- **SC =** Register sets on event occurrence and **Self-C**lears when event ends
- **RW/SC =** Read Write access/**Self C**learing bit
- **RO =** Read Only access
- **COR =** Clear on Read
- **RO/COR =** Read Only, **Clear** on **Read**
- **RO/P =** Read Only, **Permanently** set to a default value
- **LL =** Latched Low and held until read, based upon the occurrence of the corresponding event
- **LH =** Latched High and held until read, based upon the occurrence of the corresponding event

The PHY Identifier Registers #1 and #2 together form a unique identifier for the DP83848x. The Identifier consists of a concatenation of the Organizationally Unique Identifier (OUI), the vendor's model number and the model revision number. A PHY may return a value of zero in each of the 32 bits of the PHY Identifier if desired. The PHY Identifier is intended to support network management. National's IEEE assigned OUI is 080017h.
